# Mermaid AI Prompt Guide

Kani waa **Prompt (tilmaamaha)** aad siin karto AI-yada abuura ama qaabeeya jaantusyada (sida **Mermaid Chart AI**, **ChatGPT**, **Claude**, ama **Visual Studio Code Mermaid Preview**) si ay jaantuskaaga database-ka uga dhigaan mid aad u qurxoon, midabaysan, oo u habaysan qaab cajiib ah oo bandhigaaga ama buuggaaga bilicdiisa kor u qaadaya.

## 1. Prompt-ka Koowaad (Aad loo habeeyey - Optimized for Beauty & Layout)
*Koobiyeeso qoraalka hoose, kuna dheji AI-ga (ChatGPT, Claude, ama Mermaid Chart AI) adoo ku daraya koodhkii Mermaid-ka ee aan kuu sameeyay:*

```text
Please act as an expert database designer and data visualizer. I have a Mermaid ERD (Entity Relationship Diagram) code for my e-commerce project, and I want to optimize it to look extremely professional, clean, and visually stunning for a university graduation thesis and slide presentation.

Please apply the following enhancements to the diagram layout and styling:
1. Optimize the layout (direction, spacing) to minimize overlapping or crossing relationship lines.
2. If the tool supports CSS styling or thematic rendering, apply a modern, clean theme (like 'neutral', 'forest', or a professional corporate blue/gray color palette).
3. Ensure that all primary keys (PK) and foreign keys (FK) are clearly marked and aligned.
4. Keep the relationships readable: make sure relationship texts like "has", "places", "receives", etc., are aligned properly.
5. Provide the optimized Mermaid code and explain any visual layout improvements made (e.g., changes in connection directions or layout configurations).

Here is my Mermaid ERD code:
```

## 2. Prompt-ka Labaad (Custom Styling & Color Customization)
*Haddii aad rabto in aad siiso midabyo gaar ah oo la jaanqaadaya midabada websaydhkaaga ama slide-kaaga (e.g., Slate, Dark Blue, Teal):*

```text
Please style my Mermaid ER diagram to use a custom color theme. I want it to look premium and corporate. 
Please apply the following theme variables if rendering or styling the code:
- Primary/Background color for entity boxes: Light Slate Blue or soft gray (#f4f6f9)
- Border colors: Dark Navy Blue (#1e293b)
- Header background for tables: Teal or Navy Blue with white text
- Font: Inter or Roboto (clean sans-serif)
- Optimize the layout to be Top-Down (TB) or Left-to-Right (LR) depending on which layout makes the lines look cleaner with fewer crossings.

Here is my Mermaid ERD code:

[HALKAN KU DHEX DHEX-DHEJI KOODHKII MERMAID-KA]
```
