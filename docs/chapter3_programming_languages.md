## 3.X. Development Technologies and Programming Languages (Tiknoolajiyada iyo Luuqadaha Horumarinta)

Qaybtan waxay faahfaahinaysaa luuqadaha borogaraamiska (programming languages) iyo farsamooyinka loo adeegsaday dhismaha iyo horumarinta nidaamka (system-ka). Maadaama nidaamku yahay mid casri ah oo ku dhisan shabakada (Web-based application), waxaa la adeegsaday luuqadaha ugu habboon ee isku xiri kara qaybaha hore (Frontend) iyo qaybaha dambe (Backend).

### 1. JavaScript (ES6+ & JSX)
JavaScript waa luuqada ugu muhiimsan ee nidaamka oo dhan lagu dhisay (primary language), waxaana loo adeegsaday labada qaybood ee nidaamka:
*   **Qaybta Hore (Frontend - React.js):** Waxaa loo adeegsaday dhismaha qaybaha is-dhexgalka ee macmiilka (Interactive User Interfaces) iyadoo la adeegsanayo **JSX** (JavaScript XML) oo u sahlaysa React inuu koodhka HTML ku dhex qoro JavaScript.
*   **Qaybta Dambe (Backend - Node.js/Express):** Waxaa loo adeegsaday samaynta Server-ka, API-yada (Application Programming Interfaces), iyo isku-xirka database-ka, taas oo ka dhigaysa nidaamka mid hal luuqad (JavaScript) ku wada shaqeeya (Full-Stack JavaScript).

### 2. HTML5 (HyperText Markup Language)
HTML5 waa luuqada asaasiga ah ee loo adeegsaday dhismaha qaab-dhismeedka iyo laf-dhabarta bogagga internet-ka ee nidaamka. Waxay hubisaa in dhammaan walxaha shabakadda (sida qoraallada, sawirrada, foomamka, iyo badhamada) u habaysan yihiin si nidaamsan oo la jaanqaadi karta aaladaha kala duwan (semantic structure).

### 3. CSS3 (Cascading Style Sheets & Tailwind CSS)
CSS3 waa luuqada loo adeegsaday naqshadaynta, bilicda, iyo habaynta muuqaalka guud ee nidaamka. Si loo dardargeliyo dhismaha bilicda, waxaa la adeegsaday **Tailwind CSS** oo ah qaab-dhismeed (framework) CSS ah oo u sahlaya nidaamka inuu noqdo mid si toos ah ula jaanqaadi kara shaashadaha kala duwan ee moobilada iyo kombuyuutarada (Responsive Web Design).

### 4. NoSQL (JSON/BSON Data Representation)
Maadaama nidaamku adeegsanayo database-ka **MongoDB**, xogta waxaa loo kaydiyaa qaabka **BSON/JSON** (JavaScript Object Notation). Waa habka loo maamulo oo loo qaabeeyo shaxda database-ka (schema design) iyadoo la kaashanayo maktabadda **Mongoose** si loo xaqiijiyo saxnaanta xogta.

### 5. Windows Batch Scripting (Caawiye)
Waxaa la adeegsaday luuqad qoraaleedka yaryar ee Windows-ka (Batch Scripts) si loo maamulo port-yada server-ka inta lagu guda jiro horumarinta (development phase), gaar ahaan daminta iyo kicinta server-ka si toos ah (automation logs).
